# Arranjo Consultoria — site institucional (protótipo)

Site de página única da Arranjo Consultoria (Engenharia de Precisão, Escaneamento 3D a Laser).

- `index.html`: a página inteira (HTML, CSS e JavaScript no mesmo arquivo).
- `img/`: logo e imagens do portfólio.

Inclui um simulador interativo de escaneamento e interferências e um assistente virtual
com respostas baseadas no portfólio da empresa.

Para publicar com GitHub Pages: Settings → Pages → Source "Deploy from a branch" → branch `main`, pasta `/ (root)`.
